# Решение

Исправил начальный вывод и AJAX-обновление характеристик. Без выбранных категорий форма показывает только общие поля. После выбора категории PHP добавляет связанные с ней поля, не создаёт дубликаты и точно сопоставляет ID из `cat_prop`.

HTML для начальной страницы и AJAX теперь собирает одна функция. Она экранирует названия, подсказки и варианты из базы. Запрос вариантов использует подготовленный SQL-запрос.

Перед AJAX-обновлением JavaScript запоминает текст, выбранный вариант и отмеченные флажки. После замены блока он восстанавливает значения оставшихся характеристик. Повторный быстрый выбор категории отменяет предыдущий запрос, поэтому старый ответ не перезапишет новый.

Кнопка «Проверить отправку» передаёт `chpu_category` выбранных категорий и заполненные характеристики. Для мультивыбора она соединяет ID через `:::`. Строка `0` не отбрасывается.

## Проверка

- Запустил штатные smoke-тесты в Docker.
- Проверил ответы AJAX без `category`, с одной и несколькими категориями, а также с некорректным значением.
- Проверил в браузере сохранение текста, одиночного выбора, мультивыбора и нулевого числового значения после смены категорий.
- Проверил итоговый JSON через кнопку «Проверить отправку».
